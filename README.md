# Minispotify1 🎧

A premium and fully functional web music player built with HTML, CSS, and vanilla JavaScript.

## Features ✨
* **Background Play:** Music keeps playing even when minimized or in the background.
* **Premium UI:** Spotify-like responsive dark theme design built for mobile browsers.
* **Smart Controls:** Full playlist support, shuffle, loop, playback speed controller, and a sleep timer.
